# MetaBase (releases)

Public release mirror for **MetaBase** — a cross-platform PGN viewer/editor and chess-analysis app.
This repository contains **installers and release notes only** (no source code).

- Latest installer: https://github.com/metadbchess/metabase/releases/latest/download/MetaBase-win-x64-Setup.exe
- All releases: https://github.com/metadbchess/metabase/releases

MetaBase bundles the [Stockfish](https://stockfishchess.org/) engine (GNU GPL v3); its license ships
alongside the engine binary in each installer.
